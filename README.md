# 🧮 Polynomial ADT Program

Welcome to the **Polynomial ADT Program** – a C-based console application that allows you to load, manipulate, and analyze polynomial expressions using custom data structures such as **linked lists** and **stacks**.

This project is part of a university assignment and demonstrates the use of Abstract Data Types in C to perform polynomial operations like **addition**, **subtraction**, and **multiplication**.

---

## 📌 Features

- ✅ Load multiple polynomials from an input file.
- 🧾 Display polynomials in human-readable format.
- ➕ Add polynomials.
- ➖ Subtract polynomials.
- ✖️ Multiply polynomials.
- 💾 Save results to an output file (`result.txt`).
- 🖥️ Print results directly to the console.
- 🧠 Automatically combines like terms (same exponents).
- 📚 Structured, menu-driven interface.

## 📥 Input Format (`input.txt`)

Each line in the file should represent a single polynomial expression. Terms can be positive or negative and must follow this format:

3x^4 + 2x^3 - x^2 + 6 -5x^2 + 3x - 1

Spaces are allowed and will be parsed correctly.

---
## 📜 Menu Options
When you run the program, you'll see a menu like this:
********* Welcome to Polynomial ADT Program ***********

Please choose the operation you want from 1 to 8:

1. Load the polynomials from file
2. Print the polynomials
3. Make addition
4. Make subtraction
5. Make multiplication
6. Print the results to the screen
7. Print the results to the file
8. Exit from the program
Use the corresponding number to perform each operation.

## 📚 Learning Objectives
This project demonstrates:

Use of linked lists to manage dynamic polynomial terms.

Use of stacks to store and retrieve polynomial data.

Operator overloading logic (for addition, subtraction, and multiplication).

File I/O in C for reading and writing expressions.

Menu-driven program design for user interaction.
